# Cập nhật website bằng điện thoại
1. Tải `index.html` trong bộ này.
2. Mở repository GitHub → file `index.html`.
3. Chọn Edit để thay nội dung, hoặc Add file → Upload files nếu giao diện cho phép thay thế file cùng tên.
4. Giữ đúng tên `index.html`, sau đó Commit changes.
5. Vào Settings → Pages để xác nhận branch `main` và thư mục `/(root)`.
6. Mở lại website và thử nút “Gửi yêu cầu qua Zalo”.
