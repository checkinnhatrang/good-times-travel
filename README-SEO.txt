CÁCH CẬP NHẬT AN TOÀN
1. Tải xuống và giữ một bản sao index.html hiện tại trên GitHub trước khi thay đổi.
2. Mở index-seo.html kiểm tra trang; nếu đã sẵn sàng, đổi tên thành index.html rồi tải lên thư mục gốc repository và thay tệp cũ.
3. Tải robots.txt và sitemap.xml lên cùng thư mục gốc. Nếu repository đã có robots.txt hoặc sitemap.xml, hãy so sánh trước khi thay để không xóa chỉ dẫn hiện có.
4. Không xóa google38d291cc14a4a449.html (tệp xác minh Search Console) và share-image.jpg.
5. Sau khi GitHub Pages cập nhật, vào Search Console gửi sitemap.xml và kiểm tra URL trang chủ. Google không đảm bảo lập chỉ mục hoặc thứ hạng ngay lập tức.
